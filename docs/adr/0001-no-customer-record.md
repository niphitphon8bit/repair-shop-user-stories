# รุ่นนี้ไม่มีระเบียนลูกค้า

ชื่อ เบอร์โทร และ LINE เก็บไว้ในแต่ละงานซ่อมตามที่กรอก และเบอร์โทรใช้เพื่อค้นหาเท่านั้น รุ่นนี้ไม่มีกฎข้อไหนต้องรู้ว่าเป็นคนเดียวกัน เพราะลูกค้าไม่ต้องสมัครสมาชิก และลูกค้าประจำยังไม่มีนิยาม (S-28) อีกทั้งเบอร์เดียวอาจเป็นของคนทั้งครอบครัว (S-39)

ข้อเสียคือถ้าจะคำนวณลูกค้าประจำภายหลัง ต้องจับคู่ข้อมูลเก่าเอง และลูกค้าที่เปลี่ยนเบอร์ต้องค้นจากชื่อกับรุ่นเครื่อง (S-30)
